AI 语音助手 — 技术闭环文档

录音 → STT → DeepSeek 对话 → TTS → 播放 → 聆听重启

核心闭环（8 个环节）

1音频采集

AudioRecord 16kHz mono PCM 16-bit

  • App 启动后自动开始录音
  • RMS 均方根音量检测：阈值 500
  • 最小语音帧数：5 帧（~0.32s），支持"不用了"等短应答
  • 连续静音 25 帧（~1.6s）判定"说完了"
  • TTS 播放时自动停止录音，防止回声
已跑通

2语音转文字（STT）

OkHttp WebSocket bigmodel_nostream X-Api-Key 鉴权

  • WebSocket 二进制协议：4 字节 header + payload_size + payload
  • 流程：握手 → Full Client Request → 发送 PCM → 最后一包(flags=0x22) → 接收 JSON 识别结果
  • 中文识别准确率高，延迟 ~1.5s
  • 引擎：火山引擎豆包 ASR 2.0 (volc.seedasr.sauc.duration)
已跑通

3对话理解（NLU）

DeepSeek API System Prompt JSON 结构化输出

  • DeepSeek 全权管理对话状态和槽位
  • 5 个槽位：plan_name / reminder_times / repeat_mode / custom_days / category
  • 自然追问 + 确认，零硬编码状态机
  • 对话历史保留最近 8 轮上下文
  • 空白响应自动重试一次（500ms 延迟）
已跑通

4文字转语音（TTS）

HTTP POST seed-tts-2.0 MP3 分片拼接

  • 火山引擎 TTS V3 (unidirectional)
  • SSE 流式返回多块 JSON，每块含 base64 编码 MP3 片段
  • 逐行读取 + 拼接 data 字段 → Base64 解码 → 完整 MP3
  • 音色：zh_female_xiaohe_uranus_bigtts (2.0 模型)
  • speech_rate=0（可调，-50~100）
已跑通

5音频播放

MediaPlayer 临时 MP3 文件

  • 解码后的 MP3 写入临时文件
  • MediaPlayer.setDataSource() → prepare() → start()
  • 播放完成自动清理临时文件
  • onCompletion 回调触发下一步
已跑通

6聆听重启

TTS onDone 300ms echo bleed

  • TTS 播放完成 → 延迟 300ms（防止 TTS 尾音被当成用户语音）
  • 300ms 缓冲后自动重启录音
  • 对话结束（isDone / isCancel）不重启，回到 IDLE
已跑通

7计划创建

Room DB PlanRepository AlarmScheduler

  • DeepSeek 确认创建 → PlanVoiceData → PlanEntity + ReminderEntity
  • 复用现有 savePlanWithReminders()
  • 复用现有 setAlarmClock() 闹钟调度
  • 计划创建后列表页自动刷新
已跑通

8UI 状态联动

StateFlow<VoicePhase> Compose collectAsState

  • 5 种胶囊状态：IDLE / LISTENING / PROCESSING / SPEAKING / WAITING
  • VoiceRunner 持有 MutableStateFlow，Compose 订阅自动刷新
  • 颜色从品牌绿 #27AE60 改为暖姜橙 #FF7B5C
  • 激活态显示声波动画
已跑通
关键技术细节

STT WebSocket 二进制协议

Header4 字节：version(0x1) + header_size(0x1) + message_type + flags + serialization + compression + reserved
Payload Size4 字节 unsigned int32 大端
PayloadJSON（Full Client Request）/ PCM 音频（Audio Only）/ Gzip 压缩
响应解析跳过 header(4B) + 可选 sequence(4B，flags & 1) → 读 payload_size → 提取 payload JSON → 取 result.text

TTS SSE 分片拼接机制

端点POST https://openspeech.bytedance.com/api/v3/tts/unidirectional
鉴权X-Api-Key header + X-Api-Resource-Id: seed-tts-2.0
响应格式SSE 流式：每行一个 JSON {"code":0,"data":"base64..."}
拼接逻辑BufferedReader.forEachLine → 逐行 parse → 提取 data 字段 → StringBuilder 拼接 → Base64.decode → 完整 MP3
最小 MP3 阈值500 字节（防止碎片被当成有效音频播放）

DeepSeek 对话引擎

端点POST https://api.deepseek.com/v1/chat/completions
鉴权Authorization: Bearer sk-... header
模型deepseek-v4-flash (轻量快速)
System Prompt300 字角色设定：称呼"少爷"、5 槽位定义、追问规则、回复风格、JSON 输出格式
对话历史保留最近 8 轮 user/assistant 消息
槽位状态注入每条用户消息前附加 [已填槽位: plan_name=学英语, ...]
容错空白响应 trim 判空 → 500ms 后自动重试一次 → 仍失败则提示"网络不太好"
超时5 秒 withTimeoutOrNull

VAD 静音检测参数

参数值说明
采样率16000 Hz语音识别标准采样率
帧大小512 样本每帧 32ms
RMS 静音阈值500低于此值视为安静
最小语音帧数5 帧 (~0.32s)短应答"不用了"不丢
连续静音判停25 帧 (~1.6s)用户说完了
30 秒超时30 秒无语音自动回到休眠
echo bleed300msTTS 播完到录音重启的缓冲
