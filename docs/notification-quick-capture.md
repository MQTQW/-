# 通知栏快记

在「设置 → 快捷创建 → 通知栏快记」开启。之后拉下通知栏，点「记一件事」输入一句话，不必进入首页。

支持的常用表达：

- `明天晚上六点取快递`、`后天 09:30 交材料`
- `十分钟后喝水`、`半小时后出发`
- `2026-10-23 18:00 取票`、`下周二晚上七点跑步`
- `每天晚上九点读书`、`工作日早上八点开会`、`每周一、三、五晚上七点锻炼`

默认分类为「日常」，默认「仅这一次」。本地规则解析，不上传输入，也不需要 API 密钥。明确的未来时间直接保存，并展示实际日期和时间；缺少时间提供选择，仍可打开小窗自选日期。裸写「六点」、已经过去的时间、无效日期、多个时间或暂不支持的周期表达都需要确认，不会自动猜测。确认页也支持修改事项和重复方式。

创建结果通知提供「撤销」「修改」，撤销入口保留十分钟。编辑入口是独立小窗，关闭后回到原来的应用。Android 可能折叠同一应用的多条通知，需要展开通知组；部分快记通知被清理时，可在设置中「恢复快记通知」。通知栏外观和输入按钮的位置由系统决定。

## 数据与调度

- Room v6 在计划中增加 `one_time_at` 和唯一的 `creation_token`，通过 5→6 迁移保留旧数据；既有 1→5 迁移继续使用。
- 一次性计划按绝对时间调度，只触发一次，完成后取消待触发提醒，完成状态不随午夜重置。过期未完成事项仍可在首页看到，不重新安排到第二天。
- 一条通知输入使用固定创建令牌，数据库保证重试不会重复建计划。草稿和撤销标记在私有存储保留七天，通知处理与小窗保存共用保存流程。
- 通知权限由用户开启；没有准确闹钟权限时明确显示「已保存，提醒待授权」，在小窗授权后恢复调度。
- 备份格式升级为 2，包含一次性提醒的完整时间点。此功能没有引入备份导入。

## 验证

自动化测试覆盖解析歧义与非法时间、原有数据库升级、一次性触发与跨天完成、重试去重、补选时间、撤销防重建和备份时间点。设备验收需验证：通过系统 RemoteInput 创建、补选时间、小窗修改、通知撤销、锁屏到点提醒，以及覆盖安装后旧计划保留。

桌面小组件、桌面快捷入口和系统语音助手接入留待后续版本。
