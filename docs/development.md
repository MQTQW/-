# 开发说明

## 环境与构建

项目使用 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、Gradle Wrapper 与 Kotlin。最低支持 Android 10（API 29），当前 compile / target SDK 为 35。具体依赖版本以 `gradle/libs.versions.toml` 和 `app/build.gradle.kts` 为准。

将仓库根目录的 `local.properties.example` 复制为 `local.properties`，填写本机 SDK 路径。Java 路径由 `JAVA_HOME` 或 Android Studio 的 Gradle JDK 指定，不在仓库中硬编码。

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

macOS / Linux 使用 `./gradlew` 执行相同任务。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

### 可选语音配置

`local.properties` 中的 `volc.api.key` 用于火山引擎语音识别与合成，`deepseek.key` 用于对话。未使用语音时可留空；构建及本地回归测试不需要真实密钥。

此文件已从 Git 中排除。当前构建会将已配置的密钥写入 BuildConfig；正式分发前应将长期服务密钥迁至受认证的服务端，避免把它们放入 APK。核心计划、提醒与通知栏快记无需云端密钥。

### Windows 环境排查

Windows JDK 17 在中文项目路径下可能无法加载 Gradle 测试类；遇到此问题可将相同源码复制到英文路径后执行测试。

若当前 Windows 环境的 AF_UNIX 不可用，可在当前终端为 JVM 指定一个不存在的 `jdk.net.unixdomain.tmpdir`，使其回退至 TCP；无需修改系统网络配置。该处理仅针对遇到相同错误的环境，不是构建的通用前置条件。

## 提醒与完成规则

- 一个计划可以包含多个提醒。重复计划的「完成今天」记录当天打卡，不取消后续日期的重复提醒；一次性计划完成后取消尚未触发的提醒，完成状态不随午夜重置。
- 计划开关负责暂停整个计划，各提醒的开关负责暂停单个时段。一次性计划按绝对时间调度，过期未完成事项不会重新安排到第二天。
- 手动保存、语音创建、通知栏快记、删除撤销和重启恢复共用提醒同步逻辑。保存采用 Room 事务，触发时重新检查计划和提醒是否存在、启用且版本有效。
- 语音仅在点击入口并授予录音权限后开启；再次点击、超时或应用退到后台时停止。模型提取的信息经本地时间校验，并在用户明确确认后保存；保存和调度完成后才播报成功。
- 完成记录按计划及本地日期唯一保存。重复完成不会增加打卡或积分；撤销后打卡回退。已消费奖励被撤销时会抵扣后续积分，避免反复完成刷取奖励。相同应用当天的解锁重试不会重复扣分。
- 午夜执行日切，应用启动、回到前台和专注监控也会补做错过的日切。重启、应用更新、时间 / 时区改变及精确闹钟权限重新授予后恢复提醒。

声音播放、勿扰行为和后台冷启动诊断见 [闹铃播放与排查](alarm-audio.md)。通知栏输入、确认与一次性计划行为见 [通知栏快记](notification-quick-capture.md)。

## 数据与升级

计划数据库提供 **v1→v2→v3→v4→v5→v6** 的保留数据迁移。v5 为每条提醒保存调度版本，编辑前已进入处理队列的旧事件会被忽略；v6 增加一次性计划的完整时间与唯一创建令牌。旧版独立的单次 / 每天 / 每周提醒保留原规则，重新编辑提醒时采用当前计划级重复规则。

专注数据库 **v1→v2** 保留应用限制、任务和使用记录，并增加当天解锁状态。数据库不通过破坏性迁移清空用户数据。Room schema 位于 `app/schemas/`。

停用的专注规则继续显示，便于重新启用；规则更新和删除后，根据剩余有效规则重新计算锁定状态。无障碍服务订阅数据库锁状态，避免仅依赖广播和旧缓存。分类用量采集会带入应用规则中保存的分类，应用分类归属不被当作一条分类限额。

本地日期由 `DateProvider` 发布，专注、日历、统计和积分随日期变化更新。测试可使用固定 `Clock`，避免断言依赖实际执行日期。

「导出计划备份」通过系统文件选择器导出 JSON 格式 v2，包含全部计划、提醒、每日打卡统计、计划完成历史及一次性计划的完整时间点；不包含服务密钥、录音或积分余额。当前尚无应用内导入界面。

## 测试与验收

1.0.1 代码版本 `13659a8` 的本地验证结果：**101 项单元 / Robolectric 回归测试通过，Lint 0 错误、78 条警告**。这是该版本的本地结果，不代表已配置持续集成，也不代表所有机型已验证。

测试覆盖事务回滚、提醒取消 / 恢复、旧事件拒绝、打卡与积分幂等性、并发消费、日切、迁移、分类锁定、通知渠道、声音生命周期、语音确认、快记解析 / 去重 / 撤销和备份导出。

Android 15 模拟器曾在结束后台进程、进入深度休眠且不打开应用的条件下，验证到点启动闹铃并捕获到实际音频输出，同时检查自动停止与通知停止路径。这不能代替一加 ACE 2 等真机的扬声器、厂商后台管理和系统策略验收。

锁屏唤醒、厂商省电行为、真实语音服务、覆盖安装数据保留和实际声音表现仍需在目标设备上验收。通知送达本身不能证明铃声已经播放。
