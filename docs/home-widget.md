# 桌面日常卡片

v1.0.3 提供「MY PLAN · 日常卡片」，默认面向 4×2 桌面网格。实际占格和可调整范围由桌面启动器决定；支持横向和纵向调整。第一版只实现已选定的日常卡片，2×2 和 4×4 对比稿暂未实现。

长按桌面空白处 → 小组件 → MY PLAN → 日常卡片。浅色采用暖白和鼠尾草绿，深色跟随系统桌面主题。

- 时间与名称：展示未完成计划的下一条提醒，今天完成的重复计划展示下个有效日期；未来日期显示「明天」或具体日期。点击内容打开相应计划。
- 今日进度：与应用首页共用日期筛选规则，按计划计数，同一个计划的多个提醒不重复计数。
- 完成：只对今天尚未完成的下一条计划提供直接完成。重复计划完成当天，保留之后的重复规则；一次性计划标记完成。明天的提醒显示「查看计划」。
- 撤销：完成后出现「撤销」。同一小组件保留最近一次完成操作；跨天、删除或后续编辑后自动失效，避免覆盖新操作。
- ＋：直接打开快速创建小窗，默认「仅这一次」，可选择日期、时间或每天。保存使用现有计划、数据库和闹钟调度，不经过应用首页。
- 权限：通知或精确闹钟权限缺失时，顶部显示提示，点击进入相应系统设置。应用使用限额需要的无障碍权限与普通小组件无关。

没有未来提醒时，卡片根据实际情况显示「还没有待提醒的计划」「今天的计划已完成」或尚未完成的待办数量；过期的一次性待办仍可在应用中处理，不会自动改为明天提醒。

## 更新和实现

使用系统 `AppWidgetProvider` / `RemoteViews`，无需额外运行常驻服务。应用存活时观察 Room 的计划变化；保存、完成、撤销后更新，收到提醒、恢复闹钟及跨天检查时也刷新。系统另提供至少 30 分钟的周期刷新。系统可能延迟后台更新，卡片不显示需要每分钟精确刷新的倒计时；响铃仍由原有独立 AlarmManager 链路触发。

小组件操作只使用显式、不可变的 PendingIntent。完成和撤销在共享计划操作锁内校验日期、计划更新时间及完成状态；旧点击不会再次发放完成奖励，也不会完成已暂停、已删除或被编辑的计划。撤销记录保存在本机，按小组件实例隔离。

组件布局使用 Android 资源中的浅色 / 深色配色；快速创建小窗沿用应用主题。桌面小组件跟随系统主题，因此应用单独指定主题时，两者可能不同。
