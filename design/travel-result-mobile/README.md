# MY PLAN · 旅行方案手机原型

把参考图中的照片卡片和完整旅行信息适配到手机，延续 MY PLAN 的暖白与鼠尾草绿。入口是本目录的 `index.html`，也可查看交付副本 `../../delivery/travel-result-mobile-20261028/MY_PLAN-旅行方案手机原型.html`。

## 打开与构建

可直接用浏览器打开 `index.html`。它已包含样式、脚本和四张照片，不依赖在线资源。修改源码后，从项目根目录运行：

```powershell
node design/travel-result-mobile/build.mjs
node design/travel-result-mobile/serve.mjs
```

然后打开 [本地预览](http://127.0.0.1:8791)。构建只重写本目录的 `index.html`，交付副本需另行同步。脚本使用 Node.js 内置模块，无需安装依赖。

桌面上，手机两侧是预览控制和设计说明；手机宽度下，它们放到手机界面下方。向下滚动外层页面可切换暖白／深色、天气示例状态，或直接跳到辅助页；手机内容区本身独立滚动。

## 可以试的流程

- **概览**：横滑四张照片，或使用左右箭头；打开图卡后进入对应日期。预算、天气、每日速览和出处都有入口。
- **每日与地图**：选择日期，从某一站进入地图再返回。日期与选中地点保持，两个分区各自记住滚动位置。地图支持选点与缩放，仅示意地点分布；待定地点不标点，也不跨过未知地点连线。
- **地点确认**：查看待确认午餐门店，选择示例候选后应用；也可保留待定。重新搜索只演示固定候选与无结果提示。
- **编辑**：修改名称、时间、停留时长和备注。空名称、无效时间、跨午夜与同日时间重叠会提示；成功后按时间排序，保留出处，所在日交通转为待更新。雷峰塔景区与登塔内容保持同一站。
- **更多**：编辑五类预算并查看合计；切换远期／临近出发天气示例；勾选准备清单；按地点或攻略查看关联和来源详情。
- **保存与导出**：待确认项可以随草稿保存。导出会实际下载 TXT 或 JSON，并标明原型示例；TXT 包含逐日安排、备注与攻略来源附录，JSON 包含节点、预算和来源字段。

主分区支持左右方向键、Home 与 End；底部面板支持 Esc 关闭、Tab 焦点循环和关闭后焦点返回。

## 演示边界

固定样例是 2026 年 11 月 7—9 日的杭州三日行程。日期、地点、时段、费用、天气、搜索候选和攻略关联用于验证交互，未做实时核验。门票预算为 0 不代表免费。

所有修改与“已保存”状态只存在本次页面内存中，刷新即还原；未写入 Android、文件数据库或登录账户。只有用户触发导出时才生成本机下载文件。原型不调用模型、地图或天气服务，构建的内容安全策略包含 `connect-src 'none'`。

照片是独立的 Wikimedia Commons 配图，不代表攻略原帖图片。作者、许可、原始文件页与使用说明见 `credits.json` 和页面下方“配图来源与许可”；原图文件未修改，界面通过 CSS 裁切。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 可独立打开的构建产物 |
| `app.js` | 页面壳、导航、面板、共享状态、校验与导出 |
| `data.js` | 行程、照片卡、攻略和初始状态 |
| `ui.js` | 转义、内联图标和通用按钮 |
| `auxiliary.js` | 预算、天气、关联、来源辅助页及其样式 |
| `base.css` | 语义色、手机布局、响应式与交互状态 |
| `assets/`、`credits.json` | 配图原文件及署名记录 |
| `build.mjs`、`serve.mjs` | 单文件构建与本地静态预览 |
| `PRODUCT.md`、`DESIGN.md` | 设计范围与完成后的视觉／交互规则 |

## 验证记录

交付证据在 `../../delivery/travel-result-mobile-20261028/qa/`：截图与 `capture-manifest.json` 记录 320、390、800、1280 CSS 像素宽度的布局，以及深色、编辑报错、确认、保存、导出和辅助页。截图提供方可能缩放 JPEG，视口尺寸以清单为准。`checks.json` 记录浏览器流程检查、23 项逻辑断言与 3 项面板键盘断言，`export-example.txt` 是实际下载样例。

这些检查覆盖浏览器布局和交互；真实手机的触摸惯性、软键盘、设备安全区及 Android 原生集成仍需在后续实现中验收。
