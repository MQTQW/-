# 柔和陪伴 · Android 实现

本目录的交互设计稿是视觉参考；实际应用使用原生 Jetpack Compose，连接现有 Room 数据、闹钟调度与专注限制服务。

## 主题与组件

- `ui/theme`：暖白与鼠尾草绿配色、字体、圆角以及完整深色配色。显示风格设置立即生效，系统栏文字跟随主题。
- `CompanionComponents.kt`：公共页头、卡片、分组标题、主要按钮、标签与说明。
- 主导航统一处理系统栏。编辑页使用滚动内容和键盘避让；计划管理与专注详情页隐藏主导航。

## 页面与行为

- 今天：首页突出下一条有效提醒与当天待办；完成打卡不会取消重复提醒。今天已过提醒时间但尚未完成的计划仍可打卡。
- 全部计划：搜索、筛选、按创建时间排序、提醒开关、完成状态、删除和撤销。
- 新建及编辑：名称与说明、六类分类、每天/周一至周五/自定义星期、多提醒时间、逐时间开关、未保存退出确认和保存防连点。取消新增时间不会留下额外提醒。
- 日历：真实月份、星期与选中日期的计划；全部条目可滚动访问。
- 统计：真实打卡与分类数据；设计示例中的固定连续七天图示没有写入应用。
- 专注：真实应用用量、应用选择、每日限额、规则编辑/暂停/删除、权限检查及积分解锁。已有分类规则仍可显示和编辑。
- 设置：提醒方式、系统铃声选择、震动、测试提醒、权限、JSON 备份导出、外观和使用说明。
- 启动与引导：统一品牌图形、文案和页面层级。
- 语音：展示识别内容与待确认计划摘要；修改会带入全部提醒时间与自定义星期，确认后保存。保存过程中不能用取消按钮误导性地撤回已提交操作。

## 数据与范围

这次改版不改变数据库版本及迁移链，继续使用现有提醒调度和积分逻辑。设计稿中的计划、统计与用量不作为应用初始数据；安装包没有预置测试计划。

不包含一次性指定日期提醒、稍后提醒或备份导入。语音仍使用现有网络服务配置；未配置服务时可继续手动创建计划。

编辑器增加了重复加载保护：同一编辑页因配置变化重建时不会重置仍存活 ViewModel 中的未保存输入；语音摘要再次传入也不会覆盖用户已经修改的草稿。

## 构建与验证

单元与回归检查覆盖数据库迁移、提醒可靠性、打卡/积分、分类限制、调度版本、语音明确确认，以及编辑器草稿保留。最新构建结果、实际模拟器截图、APK 签名与升级验证记录随本地交付包提供。

Windows 中文路径下本机 Gradle 测试 worker 无法加载测试类，因此使用独立英文目录验证。验证前逐文件比较 SHA-256，确保源码与本工作区一致；没有修改测试断言或系统配置。
